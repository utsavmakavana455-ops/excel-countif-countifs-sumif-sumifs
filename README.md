# Excel Conditional Functions – COUNTIF, COUNTIFS, SUMIF & SUMIFS

This project contains my practical learning and exercises on Excel conditional functions used for data analysis and reporting.

## 📌 Functions Covered

### COUNTIF

Counts the number of cells that meet a single condition.

**Example:**

```excel
=COUNTIF(B2:B20,"Sales")
```

### COUNTIFS

Counts cells based on multiple conditions.

**Example:**

```excel
=COUNTIFS(B2:B20,"Sales",C2:C20,">500")
```

### SUMIF

Adds values based on a single condition.

**Example:**

```excel
=SUMIF(B2:B20,"Sales",D2:D20)
```

### SUMIFS

Adds values based on multiple conditions.

**Example:**

```excel
=SUMIFS(D2:D20,B2:B20,"Sales",C2:C20,">500")
```
